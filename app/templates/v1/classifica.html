Come si calcola il punteggio

In parole semplici

Per ogni indicatore si guarda quanto una {{ s.singular }} si allontana dalla media delle {{ d.n }}, nel verso giusto: dove è meglio un valore alto, un valore alto alza il punteggio, dove è meglio basso lo abbassa.

Gli indicatori si raggruppano in {{ d.dims_total }} dimensioni, dal reddito alla salute alla sicurezza, e le dimensioni si combinano con i pesi del profilo scelto. Il risultato va da 0 a 100{% if d.fifty %}: 50 è la media semplice delle {{ d.n }} {{ s.plural }}, e sopra 50 una {{ s.singular }} fa meglio della media{% endif %}.

Il calcolo

Metodo
Per ogni indicatore uno z-score orientato, che conserva le distanze fra i territori. Poi la media per dimensione e la media pesata delle dimensioni, riportata su una scala da 0 a 100 dove 50 è la media e una deviazione standard vale {{ d.spread }} punti.
